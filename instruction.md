# Formalization of Drazin Invertibility in Lean 4

## Problem Description
Formalize Proposition 2.4 regarding Drazin invertibility inside a Ring framework.

Assume that $a$ is Drazin invertible in $A.$ Then there exists $b \in A $ and $ k \in \mathbb{N}$ such that $ bab=b, ab=ba, a^kba=a^k.$ Without loss of generality, we can assume that $k=1.$
Show that $ A= aA \oplus N(a).$ 

## Task Requirement
Provide a mathematically sound and fully checked Lean 4 file compiled using Mathlib that models this algebraic decomposition.

You have 3600 seconds to complete this task. Do not cheat by using online solutions or hints specific to this task.
